# Tooltip

Native `title` attribute is not enough to display a tooltip. This extension will help you to **display a tooltip** on any element with `title`, but being able to **customize it**.

## How to use this extension

### Angular

<Codesandbox
  extensions={['useTooltipExtension']}

  code={`
    <span title="Example of a tooltip">Hover me</span>`}
