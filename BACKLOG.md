Canonical backlog for automation follows backlog-curator conventions in `.pm/backlog/items.yaml`.

## Top 5 priorities for a stable, modern, scalable v2

1. **BL-100 — Establish v2 quality and CI platform matrix**  
   Add lint/type/build/smoke gates across all platforms with caching and reliable CI enforcement.

2. **BL-101 — Harden multi-platform compiler transforms**  
   Replace fragile transform patches with deterministic generation and add compile contract checks.

3. **BL-102 — Deliver v2 UX correctness and accessibility baseline**  
   Fix intent semantics and enforce consistent accessibility behavior and guidance across components.

4. **BL-103 — Rebuild toast and extension runtime architecture**  
   Implement reactive, typed, lifecycle-safe extension runtime behavior for dependable UX.

5. **BL-104 — Enforce v2 performance budgets and delivery optimization**  
   Define and enforce bundle/runtime budgets and optimize docs/package delivery paths.
